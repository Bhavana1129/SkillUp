## **Overview**
**SkillUP** is a modern **MERN Stack**-based e-learning platform designed to revolutionize online learning. It features **role-based dashboards** for **Admins**, **Teachers**, and **Students**, providing a seamless experience for managing classes, assignments, and user interactions. With a **responsive design** and integrated **payment gateway**, SkillUP is the go-to platform for educational needs.

## 📜 **Project Features**

### **1. Role-Based Dashboards**
- **Student**: Enroll in classes, submit assignments, and access course material.
- **Teacher**: Manage classes, track student progress, and interact with learners.
- **Admin**: Approve/reject classes and manage users/teachers effectively.

### **2. 💻 Responsive Design**
- **Mobile-first** approach ensuring smooth access on all devices – desktops, tablets, and mobiles.

### **3. 📊 Real-Time Statistics**
- Dashboard with live statistics on users, classes, and enrollments for quick insights.

### **4. 📚 All Classes Page**
- Card-based layout showcasing class details, including teacher info, price, description, and enrollment options.

### **5. 💳 Stripe Payment Integration**
- **Seamless** class enrollments with **secure** Stripe payment integration.

### **6. 🚀 Teach on SkillUP**
- Teachers can apply to join SkillUP and submit their teaching applications for admin review.

### **7. 🏫 Student Dashboard**
- View enrolled classes, submit assignments, and manage personal profile from a central dashboard.

### **8. 🧑‍🏫 Teacher Dashboard**
- Create and manage courses, track student progress, and view class-specific analytics.

### **9. 🔧 Admin Dashboard**
- Manage users, approve/reject teachers and classes, and maintain platform integrity.

### **10. 🔒 Authentication**
- Secure login with **Google Sign-in**, form validation, and **role-based redirection**.
